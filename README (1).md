## 🚀 Getting Started

### View locally
```bash
git clone https://github.com/SHIOMKUMARTIWARI/web-dev-projects.git
cd web-dev-projects
# Open index.html in your browser
```

### Deploy on GitHub Pages
1. Go to your repo → **Settings** → **Pages**
2. Source: `Deploy from a branch`
3. Branch: `main`, folder: `/ (root)`
4. Click **Save**
5. Visit `https://SHIOMKUMARTIWARI.github.io/web-dev-projects/`

## ⚙️ Weather App Setup
The weather app requires a free API key from [OpenWeatherMap](https://openweathermap.org/api):
1. Sign up at openweathermap.org
2. Copy your API key
3. Open the weather app and paste the key in the setup field
